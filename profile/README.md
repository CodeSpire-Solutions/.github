# CodeSpire-Solutions

Hey, we build desktop tools and Android apps, mostly with Dart and Flutter. If an app can do its job offline, we build it that way. Your files stay on your device, and there’s no account to set up or analytics running in the background.

## On the workbench: NodeQL

What happens to your results when you swap an `INNER JOIN` for a `LEFT JOIN`? In **[NodeQL](https://github.com/Kartoffelspalt/NodeQL)**, you can change the block, see the SQLite update, and run the query again. Bring your own SQLite file or start with the built-in workshop.
